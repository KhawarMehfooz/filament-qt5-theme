# Security Policy

## Supported Versions

Only the latest released version of `khwr/filament-qt5-theme` is supported
with security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately via
[GitHub Security Advisories](https://github.com/KhawarMehfooz/filament-qt5-theme/security/advisories/new)
for this repository. You should receive a response within a few days.
